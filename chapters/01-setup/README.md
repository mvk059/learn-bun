# Chapter 1: Setting Up the App

This chapter walks you through the foundational steps of starting a new project with Bun. You will install Bun, initialize a project, configure TypeScript, set up environment variables, and work with basic file operations.

## Lessons

1. **Bun Basics** - Installing Bun, initializing a project, and running your first script.
2. **TypeScript Types** - Configuring TypeScript and defining the core types used throughout the tutorial.
3. **Environment Config** - Loading environment variables and creating a typed configuration module.
4. **File Operations** - Reading and writing files using Bun's built-in APIs.

## What You'll Learn

- How to install and configure Bun as your JavaScript runtime.
- How to set up a TypeScript project from scratch.
- How to manage environment-specific configuration safely.
- How to perform synchronous and asynchronous file operations with Bun.

## Prerequisites

None. This is the starting point of the tutorial.
