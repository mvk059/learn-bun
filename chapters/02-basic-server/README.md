# Chapter 2: Basic Server

This chapter introduces Bun's built-in HTTP server. You will create a minimal server, handle incoming requests, send responses, and understand the server lifecycle.

## Lessons

1. **HTTP Server** - Starting a server with `Bun.serve` and listening on a port.
2. **Request Handling** - Reading request properties such as method, URL, headers, and body.
3. **Response Building** - Constructing responses with status codes, headers, and body content.
4. **Server Lifecycle** - Managing startup, shutdown, and graceful termination.

## What You'll Learn

- How to spin up an HTTP server using Bun's native API.
- How to inspect and destructure incoming requests.
- How to build well-formed HTTP responses.
- How to handle server startup and graceful shutdown signals.

## Prerequisites

- [Chapter 1: Setting Up the App](../01-setup/) - Bun installation, TypeScript config, and environment setup.
